# Entity Relationship Diagram (ERD)

## Project: JMW Fix Track – Mobile Repair Shop Tracker

This folder contains the Entity Relationship Diagram (ERD) of my semester project.

The ERD represents the database entities, attributes, Primary Keys (PK), Foreign Keys (FK), and relationships between different entities.

### Main Entities
- Customer
- Technician
- Admin
- Repair Job
- Problem
- Payment
- Phone
